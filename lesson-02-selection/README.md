# فایل‌های همراه شناخت خانواده‌ها و انتخاب STM32

این درس دربارهٔ انتخاب تراشه است و پروژهٔ firmware یا فایل `.ioc` ندارد.

- `selection-worksheet.csv`: کاربرگ انتخاب برای 3 پروژهٔ فرضی؛ ستون‌های خالی باید با شمارهٔ دقیق قطعه و شواهد تکمیل شوند.
- `verify_buffer.py`: اسکریپت Python 3 با کتابخانهٔ استاندارد برای مثال بافر فرضی؛ اجرا: `python verify_buffer.py`.
- `buffer-results.json`: خروجی واقعی اسکریپت. 1024 نمونهٔ 2 بایتی، 2048 بایت یا 2 KiB نیاز دارد؛ پشته، heap و داده‌های دیگر جدا هستند.
- `sources.json`: منابع اولیه و تاریخ بررسی.
- دو فایل PNG: تصویر مفهومی تألیفی جبرابیت؛ تصویر نرم‌افزار یا اندازه‌گیری نیستند.
- `verification-report.txt`: حدود بررسی واقعی.

نام خانواده، انتخاب نهایی قطعه محسوب نمی‌شود. قیمت، موجودی و پشتیبانی نرم‌افزار باید در زمان طراحی دوباره بررسی شوند. هیچ نتیجهٔ اندازه‌گیری سخت‌افزاری در این بسته ادعا نشده است.
