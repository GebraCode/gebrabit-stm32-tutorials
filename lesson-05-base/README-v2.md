# قالب پایهٔ STM32F303

این قالب را برای شروع درس‌های بعد نگه دارید. تراشه STM32F303CBT6 روی برد GB100ST V2.0 است. ابتدا فایل پروژهٔ `lesson-05-project-v2.zip` را استخراج کنید و تنظیم‌های خود را با `template-checklist-v2.csv` مقایسه کنید. کاربرگ خالی است؛ مشاهدهٔ واقعی خودتان را وارد کنید.

قالب از HSI با فرکانس نامی 8 MHz استفاده می‌کند. پایه‌های کریستال HSE و LSE رزرو شده‌اند، اما کد تولیدشده آنها را روشن نمی‌کند. مقدار اسمی کریستال‌ها 8 MHz و 32.768 kHz است. PA13 و PA14 برای SWD و PB6 برای LED کاربر با خروجی اولیهٔ Low هستند. حلقهٔ اصلی خالی است؛ چشمک‌زدن انتظار این قالب نیست. انتخاب کلاک 72 MHz در درس 9 انجام می‌شود.

## ساخت و محاسبه

از ریشهٔ پروژهٔ استخراج‌شده، با CMake 3.22 یا جدیدتر، Ninja و arm-none-eabi-gcc:

```text
cmake --preset Debug
cmake --build --preset Debug --clean-first
```

این پروژهٔ CMake است. برای روش گرافیکی، از IOC یک کپی در پوشه‌ای جدا بگیرید و خروجی مناسب STM32CubeIDE را تولید کنید؛ واردکردن آن در رابط گرافیکی در این بررسی آزمایش نشده است. پس از تولید مجدد، نسخهٔ بسته و فرمان واقعی ساخت را بررسی کنید. Keep User Code جای نسخهٔ پشتیبان نیست.

برای بررسی منابع و مدل تیک در رایانه، Python 3 را کنار فایل‌های همین بسته اجرا کنید:

```text
python verify_timebase_v2.py
```

نتیجهٔ مدل، 8000 شمارش کلاک برای تیک 1 ms و LOAD مورد انتظار 7999 است؛ مقدار رجیستر روی برد خوانده نشده است. کاربرگ مشاهده، پیش‌بینی را از بررسی واقعی جدا نگه می‌دارد.

## شاهد ساخت و فایل‌ها

ساخت پاکِ مجدد با منابع بدون تغییر در 2026-11-02 و GCC 13.2.1، در Debug با `-O0 -g3 -Wall -Werror` بدون هشدار انجام شد. گزارش واقعی `build-debug-report-v2.txt` و فرمان کامپایل در `actual-main-compile-commands-v2.json` است. پروژه قبلاً با CubeMX 6.14.0، پایگاه 6.0.140 و CubeF3 V1.11.6 تولید شده است؛ شمارهٔ کاتالوگ جدیدتر ابزارها، شاهد آزمون همان نسخه نیست.

Flash در لینک 7964 بایت و ناحیهٔ RAM برابر 1584 بایت است: 12 بایت data، 32 بایت BSS، مقدار 4 بایت هم‌ترازی، 512 بایت رزرو حداقل heap و 1024 بایت رزرو حداقل stack. بخش heap/stack با هم‌ترازی 1540 بایت است. اینها مصرف اوج در زمان اجرا نیستند. در این بازنگری، تفکیک BSS و هم‌ترازیِ گزارش قبلی اصلاح شده؛ سورس پروژه تغییر نکرده است.

`toolchain-and-validation-v2.json` نسخه‌ها و حدود اعتبارسنجی؛ `source-manifest-v2.json` هش فایل‌های منابع؛ `source-evidence-v2.txt` گزیدهٔ واقعی کد تولیدی و HAL؛ و `sources-v2.json` پیوند مراجع را نگه می‌دارند. فایل‌های نمونه را جای تابع تولیدشده دوباره تعریف نکنید.

مجوزهای اصلی ST و Arm داخل ZIP منابع حفظ شده‌اند. نصب و اجرای CubeIDE، پروگرام، اندازه‌گیری کلاک و آزمون برد انجام نشده‌اند.
