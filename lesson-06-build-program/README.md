# فایل‌های همراه درس 6: ساخت و پروگرام

پروژهٔ واقعی STM32F303CBT6 روی GB100ST V2.0 از قالب درس 5 ساخته شده است. در بلوک USER CODE 3 حلقهٔ اصلی، ابتدا `HAL_GPIO_TogglePin(USER_LED_GPIO_Port, USER_LED_Pin);` و سپس `HAL_Delay(500U);` اجرا می‌شود. این برنامه برای چشمک‌زن PB6 با مدار NPN فعال High است. اجرای واقعی آن روی برد انجام نشده است.

## نسخه و تنظیمات

CubeMX 6.14.0، پایگاه DB.6.0.140، بستهٔ STM32CubeF3 نسخهٔ 1.11.6 و GCC 13.2.1 استفاده شده‌اند. ساخت‌های پاک CMake Debug و Release با -Wall -Werror بدون هشدار انجام شده‌اند. Debug واقعاً -O0 -g3 و Release واقعاً -Os -g0 دارد؛ این‌ها تنظیمات همین پروژه‌اند و پیش‌فرض همهٔ IDEها نیستند. SYSCLK و HCLK از HSI با 8 MHz تأمین می‌شوند. پایه‌های کریستال HSE/LSE رزرو شده‌اند، ولی در این مقداردهی اولیه راه‌اندازی نشده‌اند.

## محتوا

- `lesson-06-project.zip`: منابع کامل و IOC با مجوزهای ST و Arm؛ فاقد حافظهٔ موقت build.
- `lesson-06-build-artifacts.zip`: خروجی واقعی `.elf`، `.hex`، `.bin` و `.map` برای هر دو پیکربندی در زیرپوشهٔ Debug و Release.
- دو گزارش build واقعی، `size-comparison.csv` و `toolchain-and-validation.json`: نسخه‌ها، فرمان واقعی کامپایل main.c، اندازه و SHA256 خروجی‌ها.
- `verify_blink.py`: محاسبهٔ زمان اسمی و آستانهٔ انتظار HAL با Python 3؛ اجرا: `python verify_blink.py`.
- `source-evidence.txt`: کد کامپایل‌شده و رفتار دقیق HAL همان نسخه.
- دو نمودار تألیفی؛ اسکرین‌شات و نتیجهٔ اندازه‌گیری نیستند.

منابع پروژه را استخراج و از ریشهٔ آن، در محیط دارای CMake 3.22 یا جدیدتر، Ninja و arm-none-eabi-gcc اجرا کنید:

```text
cmake --preset Debug
cmake --build --preset Debug --clean-first
cmake --preset Release
cmake --build --preset Release --clean-first
```

دستورهای POST_BUILD در CMakeLists.txt فایل‌های HEX و BIN را از ELF واقعی با objcopy تولید می‌کنند. فایل BIN خام نشانی بارگذاری را در خود ندارد؛ برای این پروژه نقطهٔ شروع Flash برابر 0x08000000 است. فایل HEX رکورد آدرس دارد و ELF نمادها و اطلاعات مناسب دیباگ را هم نگه می‌دارد. اندازهٔ فایل ELF را با مصرف Flash تراشه برابر نگیرید.

برای CubeIDE، از IOC کپی جدا تهیه و با CubeMX خروجی STM32CubeIDE تولید کنید. مسیر گرافیکی CubeIDE در اعتبارسنجی ما اجرا نشده است. فایل‌های عمومی، اجرای CMake را نشان می‌دهند. تولید مجدد می‌تواند تنظیمات ساخت را تغییر دهد؛ قبل از ساخت بعدی گزینه‌های هشدار و تولید HEX/BIN را بررسی کنید.

## زمان‌بندی و وضعیت آزمایش

دو نیم‌دورهٔ درخواستی 500 ms، فرکانس اسمی حدود 1 Hz می‌دهند. در HAL همین نسخه، HAL_Delay(500) با تیک پیش‌فرض، آستانهٔ مقایسهٔ 501 تیک دارد. فاز تیک، اجرای دستورها، وقفه‌ها و خطای کلاک بر اندازه‌گیری اثر دارند؛ دورهٔ واقعی یا Jitter اندازه‌گیری نشده است.

هیچ اتصال به ST-LINK، پروگرام، تغییر Option Bytes یا آزمون روی برد انجام نشده است. برای اتصال، از نام سیگنال و راهنمای پروگرامر خود استفاده کنید، نه شمارهٔ فرضی پایهٔ یک هدر. زمین مشترک و سطح منطقی 3.3V لازم‌اند. ورودی تغذیهٔ 5V برد با مرجع ولتاژ هدف پروگرامر فرق دارد. در نمونه‌هایی که VTref دارند آن پایه ورودی حس ولتاژ است؛ پایهٔ خروجی تغذیهٔ 3.3V برخی پروگرامرها را بدون بررسی راهنما معادل VTref فرض نکنید و دو خروجی تغذیه را به هم وصل نکنید.

گزارش لینک: Debug برابر 8112 بایت Flash و Release برابر 3688 بایت Flash؛ RAM هر دو 1584 بایت شامل رزرو heap/stack است و مصرف لحظه‌ای اجرا نیست. خواندن Option Bytes با نوشتن آن فرق دارد؛ این پروژه هیچ تغییر RDP انجام نمی‌دهد.

## مجوز

مجوزهای اصلی ST و Arm در منابع حفظ شده‌اند. بستهٔ عمومی اطلاعات ورود، حافظهٔ موقت ساخت یا تنظیمات شخصی ندارد.
