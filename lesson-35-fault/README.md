# درس 35: دیباگ پیشرفته و تحلیل خطاهای Fault

منابع همراه آموزش STM32 سایت [جبرابیت](https://gebrabit.com)؛ هدف **STM32F303CBT6، بستهٔ LQFP48، برد GebraBit GB100ST V2.0**.

[دانلود همهٔ فایل‌های همراه](lesson-35-resources.zip)

پس از دریافت، آرشیو را باز کنید و README داخل بسته را بخوانید. بسته شامل پروژهٔ کامل و IOC، کدها و مجوزها، خروجی ELF/MAP/BIN و گزارش کامپایل، شکل‌های تألیفی و فایل‌های قابل ویرایش آن‌ها، اسکریپت‌ها و راهنمای آزمایش است. دادهٔ مدل و مقدار مورد انتظار، نتیجهٔ اندازه‌گیری روی برد نیستند.

## وضعیت اعتبارسنجی

پروژهٔ واقعی با GCC13.2.1 در حالت Debug و گزینه‌های `-O0 -g3 -Wall -Werror` بدون خطا و هشدار کامپایل شده است. کد و خروجی ساخت بررسی شده‌اند. اجرای فیزیکی روی برد، اجرای رابط گرافیکی دیباگر و اندازه‌گیری با اسیلوسکوپ یا لاجیک آنالایزر در این تحویل انجام نشده‌اند.
