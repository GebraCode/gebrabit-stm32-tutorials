# فایل‌های همراه درس 8: GPIO و کلید بدون توقف برنامه

پروژهٔ واقعی gebrabit_lesson08_gpio برای STM32F303CBT6 روی GB100ST V2.0 است. فایل IOC و سورس‌های تولیدشده و کد کاربر در lesson-08-project.zip قرار دارند. تمام LICENSEهای موجود در پروژه حفظ شده‌اند. ساخت CMake واقعی با CubeMX6.14.0، DB6.0.140، CubeF3V1.11.6 و GCC13.2.1 انجام شده است. Debug با -O0 -g3 -Wall -Werror بدون هشدار ساخته شد: Flash8288 بایت و RAM1592 بایت. RAM ناحیهٔ لینک شامل رزرو heap/stack است و مصرف لحظه‌ای نیست. ELF و MAP واقعی جداگانه در lesson-08-build-artifacts.zip قرار دارند. فرمان دقیق و هش‌ها در manifest ثبت شده‌اند.

## مدار واقعی برد

کلید USER BUTTON از قبل روی برد به PA3 متصل است؛ کلید خارجی لازم نیست. R17=0 Ohm، R2=10 kOhm به3V3 و C2=100 nF بهGND در شماتیک وجود دارند. فشار کلید ورودی را LOW می‌کند. در این پروژه GPIO_NOPULL انتخاب شده، زیرا مقاومت خارجی وجود دارد. ثابت زمانی اسمی RC برابر1ms است و اثبات حذف تمام جهش‌ها نیست. Pull-up داخلی برای مقایسهٔ آموزشی توضیح داده می‌شود و در این پیکربندی فعال نیست. PB6 به بیس ترانزیستور NPN مدار LED متصل است و HIGH باعث روشن‌شدن LED می‌شود. خروجی push-pull، سرعتLOW و مقدار اولیهLOW است. اعداد جریان حداکثر مطلق را هدف طراحی ندانید؛ یادداشت منابع شرایط واقعی دیتاشیت را تفکیک می‌کند.

## الگوریتم و محدودیت شمارش

پس از تنظیم GPIO، raw_level و stable_level از نمونهٔ فیزیکی اولیه پر می‌شوند. اگر کلید هنگام راه‌اندازی نگه داشته شده باشد، فشار ساختگی شمرده نمی‌شود؛ ابتدا رها و دوباره فشرده شود. هر تغییر مشاهده‌شدهٔ نمونه raw_changes را افزایش می‌دهد و زمان تغییر ثبت می‌شود. اگر سطح نمونه حداقل20ms تغییر نکند، وضعیت پایدار به‌روزرسانی می‌شود. تنها پذیرش LOW، debounced_presses را افزایش می‌دهد و LED را Toggle می‌کند؛ رهاکردن LED را تغییر نمی‌دهد. فشار ممتد یک رخداد دارد.

raw_changes تعداد لبه‌های مشاهده‌شده در polling است، شامل فشار و رهاکردن؛ تعداد تمام جهش‌های فیزیکی نیست. تفاضل آن با debounced_presses نیز تعداد bounce نیست. سخت‌افزار RC و فاصلهٔ نمونه‌برداری مشاهده‌ها را تغییر می‌دهند. حلقه HAL_Delay ندارد، ولی پیوسته CPU را درگیر polling می‌کند. تفاضل بدون علامت HAL_GetTick عبور معمول از مرز32بیتی را تحمل می‌کند؛ این ادعای زمان‌بندی دقیق واقعی یا توقف‌های نامحدود نیست. آستانه20ms یک انتخاب آموزشی است و باید برای کلید و کاربرد ارزیابی شود.

## کلاک و مسیر بازسازی

HSI8MHz منبع واقعی SYSCLK است؛ PA13/PA14 برای SWD باقی می‌مانند. پایه‌های کریستال HSE/LSE رزرو شده‌اند ولی SystemClock_Config تنها HSI را راه‌اندازی می‌کند؛ فعال‌بودن اسیلاتور خارجی ادعا نشده است. HAL و SysTick پیش‌فرض1ms حفظ شده‌اند. همهٔ منطق برنامه در USER CODE قرار دارد. منبع پروژه شامل CMakePresets است؛ با ابزارهای ARM/CMake/Ninja مناسب از cmake --preset Debug و cmake --build --preset Debug استفاده کنید. مسیر کامپایلر را متناسب با محیط خود تنظیم کنید. کار با GUI نرم‌افزار CubeIDE یا فلش‌کردن برد در این کار آزموده نشده است.

verify_debounce.py مدل محاسباتی با کتابخانهٔ استاندارد Python3 است؛ اجرا کنید: python verify_debounce.py. نتیجه و نمودارها دادهٔ مصنوعی‌اند، نه اسیلوسکوپ، شبیه‌ساز پردازنده یا اجرای برد. تست‌ها شامل جهش فشار/رهاکردن، نگه‌داشتن کلید، راه‌اندازی با کلید پایین، پالس کوتاه، مرز19/20ms، سرریز tick و تفاوت نمونه‌برداری هستند. برای آزمایش فیزیکی کاربرگ hardware-worksheet.csv عمداً خالی است. فایل‌های شواهد، نسخه‌ها و گزارش واقعی ساخت در همین بسته وجود دارند.
