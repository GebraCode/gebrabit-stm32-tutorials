# آشنایی با STM32 و هستهٔ Cortex-M

فایل‌های همراه درس 1 دورهٔ STM32 جبرابیت، برای STM32F303CBT6 روی برد GB100ST با شماتیک V2.0.

[مقالهٔ آموزشی](https://gebrabit.com/blog/getting-started-with-stm32-arm-cortex-m-microcontrollers/)

## محتوای پوشه

- `verify_memory.py`: اسکریپت مستقل Python 3 برای بازتولید محاسبات حافظه، بدون کتابخانهٔ جانبی.
- `device-facts.json`: مقادیر ظرفیت حافظه از جدول مقایسهٔ قطعات در DS9118 Rev 14؛ این ورودی‌ها دستی از سند رسمی خوانده شده‌اند.
- `memory-results.json`: خروجی محاسبات؛ SRAM اصلی 32 KiB و CCM برابر 8 KiB، جمع RAM برابر 40 KiB است.
- `board-identification.csv`: کاربرگ مشاهدهٔ برد در حالت بدون تغذیه؛ ستون‌ها توسط خواننده تکمیل می‌شوند و نتیجهٔ آزمون انجام‌شده نیستند.
- `stm32f303-overview.png`: شکل مفهومی تألیفی؛ نقشهٔ کامل باس یا نقشهٔ اتصال پایه‌ها نیست.

## اجرا

```sh
python verify_memory.py
```

اسکریپت فایل `device-facts.json` را از همین پوشه می‌خواند، محاسبات را بررسی می‌کند و `memory-results.json` را در همین محل می‌نویسد. اگر مقدارها با تراشهٔ این درس متفاوت باشند، خطا گزارش می‌شود. برای تراشهٔ دیگری از نتایج این مثال استفاده نکنید.

## وضعیت بررسی

اسکریپت اجرا شده و محاسبات نمونه با خروجی فایل JSON تطبیق داده شده‌اند. محتوای درس مفهومی است و کد قابل پروگرام روی MCU، پروژهٔ CubeMX یا گزارش کامپایل C ندارد؛ ایجاد و پروگرام پروژه در درس‌های بعد آموزش داده می‌شود. اجرای برد و اندازه‌گیری سخت‌افزاری برای این بسته ادعا نشده است.
