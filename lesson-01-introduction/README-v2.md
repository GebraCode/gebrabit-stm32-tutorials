# شناخت برد و محاسبهٔ حافظه

برد خاموش و شماتیک را کنار هم بگذارید. در کاربرگ، ابتدا پیش‌بینی سند را بخوانید و سپس مشاهدهٔ خود را ثبت کنید. خانهٔ خالی به معنای مشاهده‌نشدن است. ظاهر برد سلامت الکتریکی آن را تأیید نمی‌کند؛ در این تمرین تغذیه یا پروگرامر وصل نکنید.

برای محاسبات، Python 3 را در رایانه اجرا کنید:

```text
python verify_memory.py
```

`memory-results.json` خروجی بازتولیدپذیر است. حالت اول، 1024 دادهٔ 4 بایتی را حساب می‌کند: 4096 بایت؛ با کسر همین بافر از SRAM اصلی، 28672 بایت باقی می‌ماند. این عدد RAM آزادِ برنامه نیست. حالت دوم 2 بافر 16 بیتی و 6144 بایت بودجهٔ فرضی برای مصرف‌کنندگان دیگر دارد. حالت سوم نشان می‌دهد جمع 40 KiB رم، امکان جاگذاری یک بافر DMA به اندازهٔ 40000 بایت در SRAM اصلی 32 KiB را نمی‌دهد.

فایل `device-facts.json` مشخصات مدل CB را نگه می‌دارد؛ اعدادِ حداکثر خانواده روی جلد دیتاشیت را جای آن نگذارید. `sources.json` مسیر اسناد را مشخص می‌کند. شماتیک فقط برای مراجعه پیوند داده شده و بازنشر نشده است.

این بسته پروژهٔ MCU، فایل .ioc یا کد C ندارد. فقط محاسبات روی رایانه اجرا شده‌اند؛ شناسایی برد واقعی، نصب ابزار و آزمون سخت‌افزار همچنان بر عهدهٔ خواننده و در انتظار ثبت شاهد هستند.
